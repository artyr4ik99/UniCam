# Universal Camera Viewer (бывш. Tiandy Multi Viewer)

Просмотр и анализ нескольких IP-камер (RTSP/ONVIF) **любого производителя** —
Tiandy, Hikvision, Dahua, Uniview, Reolink, Foscam, Axis, Hanwha/Samsung, Bosch,
Vivotek, Amcrest, TP-Link/Tapo и других камер со стандартным RTSP/ONVIF:
раскладки, двойной поток, запись (всегда/по движению/выключено, без
перекодирования через ffmpeg -c copy), аппаратное декодирование, звук,
цифровой зум, улучшение картинки, перетаскивание плиток, индикаторы состояния,
полноэкранный режим, неоновый интерфейс.

Поиск камер в сети умеет сканировать не только домашнюю `/24`, но и целые
блоки вида `10.x.x.x` (до `/16` за один запуск — наберите `10.0.0.0/16` или
нажмите соответствующую кнопку-пресет), подбирает типовые заводские
логины/пароли на найденных устройствах и позволяет добавить в просмотр либо
одну выбранную камеру, либо сразу все камеры с подобранным паролем одной
кнопкой. **Используйте сканер и подбор паролей только на своей сети или там,
где у вас есть явное разрешение на аудит** — для сетей крупнее 1024 адресов
программа требует подтверждения этого флажком.

## Сборка .exe через GitHub Actions

Сборка идёт на сервере GitHub (Windows), поэтому собрать можно даже с телефона
(Termux), без своего Windows-компьютера.

### Первая публикация репозитория (Termux)

```bash
pkg install git -y
cd /путь/к/папке/с/проектом      # где лежат tiandy_viewer.py, requirements.txt и т.д.
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
git push -u origin main
```

Готово — сразу после пуша во вкладке репозитория **Actions** запустится сборка.
Через 3–5 минут в том же workflow-run появится артефакт
`TiandyViewer-windows` — zip с `TiandyViewer.exe`, `ffmpeg.exe`, `ffplay.exe`.

### Обновить код и пересобрать

```bash
cd /путь/к/папке/с/проектом
git add .
git commit -m "update"
git push
```

### Выпустить релиз (постоянная ссылка на .exe)

```bash
git tag v1.0.0
git push origin v1.0.0
```

После пуша тега появится релиз на странице **Releases** с готовым
`TiandyViewer-windows.zip`, который можно скачивать напрямую.

## Важно

* `ffmpeg.exe`/`ffplay.exe` нужно распаковать рядом с `TiandyViewer.exe` (они
  уже лежат вместе в zip-архиве релиза) — иначе запись без перекодирования,
  аппаратное декодирование и звук будут недоступны (само видео по RTSP при
  этом всё равно работает).
* При первом запуске `TiandyViewer.exe` Windows SmartScreen может предупредить
  о неизвестном издателе — это нормально для самостоятельно собранных exe без
  цифровой подписи, жмите «Подробнее» → «Выполнить в любом случае».
* Поле подсети в «Поиск камер в сети» принимает как полный CIDR
  (`10.0.0.0/24`, `10.0.0.0/16`), так и короткие формы (`10.0.0`, `192.168.1.x`).
* Кнопка «Добавить все найденные камеры» добавляет в просмотр сразу все
  устройства, для которых сканер подобрал заводский логин/пароль — камеры уже
  в списке (по IP+порту) повторно не добавляются.
